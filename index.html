Phoebus

Radiant Reddit Browsing.

Phoebus is a native iOS Reddit client that recreates the experience of Apollo for Reddit together with the features of the Apollo Reborn tweak, written from scratch in SwiftUI. The core app is original code; Apollo Reborn's features are ported directly from its GPL-3.0 source.

Get it

  • Source code, issues and releases on GitHub
  • Install with AltStore or SideStore; Phoebus is not on the App Store
